# 100794414-5EN512
Marc Schumacher 5EN512 CW1A OSC Control Technology Demo


A Processing based graphical mixer that communicates with REAPER using OSC (Open Sound Control) commands. the interface is designed to control 4 channels (tracks) and a master channel along with trasnsport controls, standard channel controls, four EQ-band controls and VU meters.

Features
-4x channel strips a master channel strip
-Track and master channel pan knobs
Track and master channel volume fadera







NETWORK AND IP ADDRESSES
DEVICE NAME: OSC
DEVICE IP: 127.0.0.1
DEVICE PORT:9000
LISTEN PORT:8000
